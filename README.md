# Campus Cafe

## 프로젝트 소개

Campus Cafe는 캠퍼스 구성원이 음료 메뉴와 옵션을 선택해 주문하고, 관리자가 주문 상태와 메뉴 재고를 확인할 수 있는 카페 주문 웹앱입니다.

고객 주문부터 관리자 확인까지 한 페이지에서 이용할 수 있도록 구성했습니다. 별도 서버 없이 브라우저의 `localStorage`에 주문과 재고를 저장해 같은 브라우저에서 새로고침한 뒤에도 정보를 확인할 수 있습니다.

## 주요 기능

- 아메리카노, 카페라떼, 바닐라라떼, 카푸치노, 초코라떼 5종 메뉴와 메뉴별 재고 표시
- 샷 추가(+500원), 시럽 추가(+0원) 옵션 선택
- 옵션이 반영된 메뉴를 장바구니에 담기, 항목 삭제, 수량 및 합계 자동 계산
- 재고를 초과해 담거나 주문할 수 없도록 제한
- 주문 생성 시 메뉴별 재고 차감 및 재고가 0이 된 메뉴 품절 표시
- 관리자 화면에서 전체 주문의 메뉴, 옵션, 수량, 단가, 항목별 금액, 주문 시각, 총액 확인
- 주문 상태를 `제조 대기`에서 `제조 완료`로 변경
- 같은 페이지에서 고객 화면과 관리자 화면 전환
- 주문 정보와 재고를 `localStorage`에 저장해 새로고침 후 유지
- 모바일과 PC 화면에 대응하는 반응형 레이아웃

## 고객 화면 사용 방법

1. 상단의 **고객 화면**을 선택합니다.
2. 메뉴 카드에서 원하는 음료의 샷 또는 시럽 옵션을 선택합니다.
3. **장바구니 담기**를 눌러 메뉴를 추가합니다. 같은 음료도 옵션 조합이 다르면 각각 별도 항목으로 담깁니다.
4. 장바구니에서 항목과 합계를 확인하고, 필요하면 **삭제**를 눌러 항목을 제거합니다.
5. **주문하기**를 누르면 주문이 생성되고 재고가 차감됩니다. 주문이 완료되면 장바구니가 비워집니다.
6. 재고가 부족하거나 품절된 메뉴는 담거나 주문할 수 없습니다.

## 관리자 화면 사용 방법

1. 상단의 **관리자 화면**을 눌러 대시보드로 전환합니다.
2. **주문 현황**에서 전체 주문을 최신순으로 확인합니다. 주문별 메뉴, 옵션, 수량, 단가와 항목별 금액, 주문 시각, 총액 및 상태가 표시됩니다.
3. `제조 대기` 주문의 **제조 완료** 버튼을 누르면 상태가 변경됩니다. 완료된 주문도 목록에 남습니다.
4. **메뉴별 재고**에서 음료 5종의 남은 수량과 품절 여부를 확인합니다.
